# PayFast - Responsive Payment Website

This project is a modern, responsive web layout for **PayFast**, a digital payments platform. It includes a full UI structure with a navbar, hero section, product highlights, features, and footer. The design is clean, lightweight, and mobile‑friendly.

---

## 🚀 Features

* Fully responsive layout (mobile, tablet, desktop)
* Sticky navigation bar
* Modern hero section with CTA buttons
* Features grid section
* Product highlight sections with alternating layouts
* Clean and minimal footer
* Smooth hover effects and shadows

---

## 📂 Project Structure

```
project-folder/
├── index.html
├── style.css
└── assets/
    ├── images/
    └── icons/
```

---

## 📄 Technologies Used

* **HTML5** for structure
* **CSS3** for styling
* **Flexbox** & **CSS Grid** for layout
* **Media queries** for responsiveness

---

## 📱 Responsive Behavior

* Desktop: Full layout with 3‑column grids
* Tablet: Reduced spacing and stacked sections
* Mobile: Hamburger menu enabled; single‑column layout

---

## ⚙️ How to Use

1. Download or clone the project folder.
2. Open `index.html` in any browser.
3. Make edits in `style.css` to customize themes or colors.

---

## 🧩 Customization
